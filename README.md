## 📁 Contenido del Repositorio

- **`PFO1-Berger Rodrigo/`**: Implementación de un chat básico cliente-servidor mediante sockets TCP y persistencia en base de datos relacional SQLite (`chat_db.sqlite`).
- **`PFO2/`**: Sistema de gestión y autenticación de usuarios con API REST (Flask), almacenamiento seguro con hashing criptográfico (`werkzeug.security`) y base de datos relacional SQLite.
- **`PFO3/`**: Rediseño del sistema como arquitectura distribuida con sockets TCP en Python, implementación de **Pool de Workers** con cola sincronizada (`queue.Queue`) y diagrama arquitectural (Nginx, RabbitMQ, Workers, PostgreSQL y S3).
- **`Apuntes/`**: Material de lectura, diapositivas y apuntes teóricos de las clases.
- **`Consigna PFO/`**: Enunciados y requerimientos oficiales de los trabajos prácticos.
- **`Devoluciones/`**: Calificaciones y retroalimentaciones docentes de las entregas.
- **`Ejercicios Resueltos/`**: Guías de ejercicios prácticos desarrollados a lo largo de la cursada.
